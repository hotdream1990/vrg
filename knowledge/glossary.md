# Thuật ngữ

| Thuật ngữ | Nghĩa |
|---|---|
| **VRG** | Tập đoàn Công nghiệp Cao su Việt Nam (Vietnam Rubber Group) — khách hàng |
| **DRG** | Bí danh nội bộ của VRG dùng trong deck thuyết trình |
| **VRA** | Hiệp hội Cao su Việt Nam |
| **BCTM** | Báo cáo (số liệu) tồn kho, sản lượng nội bộ VRG |
| **Physical Price** | Giá giao dịch thực tế (khác giá sàn future) |
| **SVR** | Standard Vietnamese Rubber — cao su định chuẩn VN (SVR 10/20/CV/L/3L) |
| **RSS3** | Ribbed Smoked Sheet grade 3 — cao su tờ xông khói |
| **TSR20** | Technically Specified Rubber 20 (tương đương nhóm SVR20) |
| **TOCOM** | Tokyo Commodity Exchange (thuộc JPX) |
| **SICOM / SGX** | Singapore Exchange — sàn phái sinh cao su |
| **SHFE** | Shanghai Futures Exchange |
| **AFET** | Agricultural Futures Exchange of Thailand |
| **ANRPC** | Association of Natural Rubber Producing Countries |
| **LGM** | Malaysian Rubber Board — nguồn giá physical |
| **MAPE** | Mean Absolute Percentage Error — đo sai số dự báo |
| **Bull/Base/Bear** | 3 kịch bản dự báo: tăng / ổn định / giảm |
| **RAG** | Retrieval-Augmented Generation — hỏi đáp dựa trên tri thức + citation |
| **Zero Data Retention** | Cam kết LLM API không lưu prompt/response để huấn luyện |
| **Premium/Discount** | Chênh lệch giá sàn VRG so với giá quốc tế |
